# Meu Portfólio

> Projeto Vite + React mínimo para seu currículo/portfólio.

Pré-requisitos:
- Node.js 18+ e npm

Comandos:

```powershell
npm install
npm run dev
# abrir http://localhost:3000
```

Publicação:
- Inicialize um repositório Git e faça push para o GitHub.
- Conecte o repositório no Vercel (import project) e faça deploy.
- Para domínio personalizado, adicione no painel Vercel e configure DNS no provedor.

Personalize `src/App.jsx` com seu nome, projetos e contatos.
